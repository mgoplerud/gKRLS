## Package Overview

gKRLS (Generalized Kernel Regularized Least Squares) is an R package implementing Chang and Goplerud (2024)'s generalization of KRLS as a smooth term for mgcv. It uses random sketching for scalability and provides marginal effects calculation. Published on CRAN.

## Build & Test Commands

# Full package check (standard R package workflow)

## Architecture

### Core Flow
The package implements a custom mgcv smooth class (`gKRLS.smooth`). Users specify kernels via `s(x1, x2, bs = "gKRLS", xt = gKRLS(...))` in mgcv's `gam()` or `bam()` formulas.

### Key Source Files

**R/**
- `main_function.R` — User-facing `gKRLS()` function for specifying smooth term options (kernel type, bandwidth, sketching)
- `mgcv_function.R` — mgcv integration: `smooth.construct.gKRLS.smooth.spec()` builds the kernel/penalty matrix, `Predict.matrix.gKRLS.smooth()` handles prediction
- `kernel_function.R` — Kernel utilities: sketching matrix creation, design standardization, bandwidth calibration
- `AME_function.R` — Largest file (~57KB). All marginal effects logic: `calculate_effects()`, `get_individual_effects()`, `calculate_interactions()`. Supports numerical derivatives, conditional effects, robust/clustered SEs
- `ml_function.R` — ML framework wrappers: `SL.mgcv()` for SuperLearner, `LearnerClassifBam`/`LearnerRegrBam` for mlr3, DoubleML integration
- `generic_function.R` — S3 methods including `estfun.gam()` for sandwich-based robust SEs
- `mfx_function.R` — Deprecated `legacy_marginal_effect()` (analytical approach)

**src/ (C++ via RcppEigen)**
- `marginal_effects.cpp` — Performance-critical marginal effects computation; handles Gaussian/Logit/Poisson/Probit link functions
- `calc_kernel.cpp` — Gaussian kernel calculation
- `sketch_kern.cpp` — Sketch matrix construction
- After modifying C++ files, run `Rcpp::compileAttributes()` then rebuild

### Sketching Methods
The package supports `subsampling` (default), `gaussian`, `bernoulli`, `none` (full kernel), and `custom` sketching for scalability. Default sketch size: `5 * ceiling(N^(1/3))`.

### Testing
- Framework: testthat (12 test files in `tests/testthat/`)
- Tests cover: kernel computation, calibration, marginal effects, standard errors, factor handling, interactions, DoubleML integration, KRLS compatibility
- `test_torch.R` is excluded from CRAN builds (in `.Rbuildignore`)
- CRAN tests use `set.seed(124)` for reproducibility
